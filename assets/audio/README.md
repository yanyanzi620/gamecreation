# 净化协议 · 音频素材包

和 UI 图标一样，**音频与代码完全解耦**：换音效/换音乐不用改一行脚本。

```
assets/audio/
├─ manifest.json      事件名 -> 文件 + 播放参数（改这里就能换文件、调音量、加变体）
├─ sfx/               音效
│   ├─ jet_fire.wav     射流发射
│   ├─ jet_hit.wav      射流命中（消融）
│   ├─ pickup.wav       养分拾取
│   ├─ block_place.wav  阻隔带落位
│   ├─ block_arm.wav    阻隔带生效（墙立起来）
│   ├─ block_die.wav    阻隔带自溶
│   ├─ fuse_place.wav   引信落位
│   └─ fuse_pulse.wav   引信爆开
├─ bgm/
│   └─ bgm_lung.wav     器官内嗡鸣（16 秒无缝循环）
└─ README.md          本文件
```

> 现在这批是**程序合成出来的占位音**（正弦扫频 + 滤波噪声，无版权问题），
> 作用是把整条音频链路跑通、把节奏和音量试出来。正式版整套替换即可。

## 规格（做正式素材照着来）

| 项 | 要求 |
|---|---|
| 格式 | 音效用 WAV（16bit）或 OGG；BGM 建议 OGG（体积小） |
| 采样率 | 44100Hz；单声道优先（2D 俯视不需要空间定位） |
| 长度 | 音效 0.05~1.0 秒，越短越"利落"；BGM 8~30 秒一段，可循环 |
| 电平 | 峰值不超过 **-3dBFS**；同类音效之间的响度要接近，别一个炸麦一个听不见 |
| 循环 | BGM 必须**首尾电平对齐**（最后一帧 ≈ 第一帧），否则每圈都会"啪"一下 |

## 事件表（`manifest.json`）

| 事件 | 触发时机 | 建议听感 |
|---|---|---|
| `jet_fire` | 每次射流发射 | 短促气流，**0.22 秒一发**也不能糊 |
| `jet_hit` | 射流命中病毒 | 闷响 + 撕裂感，比 `jet_fire` 更钝 |
| `pickup` | 尸体被吸成养分 | 极小的高频提示，**绝不能抢主音** |
| `block_place` | 阻隔带放下（闪烁期） | 落子感，轻 |
| `block_arm` | 阻隔带生效 | 上扫"立起来"，有存在感 |
| `block_die` | 60 秒到点自溶 | 下扫消散，别像爆炸 |
| `fuse_place` | 引信落位 | 机械扣响 |
| `fuse_pulse` | 引信爆开 | 低频核爆，全套里最重的一发 |
| `bgm` | 进关播放 | 器官内的低频嗡鸣 + 呼吸起伏，不抢戏 |

## 播放参数

| 字段 | 含义 | 调法 |
|---|---|---|
| `volume_db` | 相对总线音量 | 负数=更轻；-6 大约是"清晰但不吵" |
| `pitch_jitter` | 音高随机浮动（0.1 = ±10%） | 提高可以掩盖重复感；超过 0.25 会失真 |
| `min_gap_ms` | 同名事件最短间隔 | 连发武器靠这个防"糊成一片"，射流给 40ms |
| `loop` | 是否循环（BGM 用） | 代码会给 WAV 设 `LOOP_FORWARD` |

## 三种替换方式

1. **同名覆盖**（最省事）：`sfx/jet_fire.wav` 直接换成自己的文件，`manifest.json` 不用动。
2. **换文件名/换格式**：改 `manifest.json` 里对应 `files` 的值，例如 `["sfx/jet_fire_v2.ogg"]`。
3. **加变体**：`"files": ["sfx/jet_hit_1.wav", "sfx/jet_hit_2.wav"]`，每次播放随机挑一个，重复感立刻下降。

## 已知约束

- 文件缺失时该事件**静默跳过**，不报错、不崩（所以删文件不会炸游戏，只会变哑）。
- 加载逻辑在 `scripts/audio/audio_director.gd`，读的是本目录的 `manifest.json`。
- `.json` 不是 Godot 资源，导出时要把 `*.json` 加进「非资源文件过滤」。
- 无头模式（`--headless`，自测/CI）会自动静音，不会刷音频设备告警。
