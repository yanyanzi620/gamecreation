## 1. 设计定位

- **题材**：人体内部免疫战争。病毒是粒子态的活体污染，玩家是免疫单元。
- **类型**：动作肉鸽（Roguelike-lite）。每局一张器官地图，手段靠养分兑换，失败即重开。
- **视角**：2D 俯视，相机跟随，`zoom 1.45`（一屏约 1.5~2 个肺泡腔室）。
- **节奏**：不是回合制，是「实时压力 + 决策调度」。战线拉长靠器官之间的连通与封锁成本，不靠倒计时。
- **胜负**：全身感染度低于阈值并维持一段时间 → 胜利；脑死亡 → 失败。（**未实现**）
- **多人**：两人共用一张全身免疫图，一人清毒、一人修复；单元的调度必须走血管（瞬移）。（**未实现**）

### 1.1 三条不妥协的手感口径

1. **地图必须铺满、有压迫感**，且形状是器官本身（不是方形场地）。
2. **病毒必须是粒子态、复制式扩张**，打上去是「一片一片被吃掉」，不是打一个圆环。
3. **所有平衡数字集中在 `balance.gd`**，任何模块不许写死数值。

## 2. 核心循环

### 2.1 现在能玩到的循环（已实现）

```
观察（小地图看感染分布）
  → 走位（贴墙滑行，在肺泡之间钻通道）
  → 输出（左键射流扇形清一片，被墙/阻隔带截断）
  → 收益（尸体留疤 30s → 自动拾取 → 养分）
  → 决策（养分换：阻隔带封路 / 引信清场）
  → 压力（病毒继续复制，封路会养出更密的一坨）
```

### 2.2 设计目标循环（未完成部分用 ⏳ 标）

```
观察 → 调度（⏳ 在多单元之间瞬移接管，走血管）→ 输出 → 收益
  → 修复（⏳ 清病毒尸体残留，巨噬细胞回收换酶）
  → 换手段（⏳ 布洛芬 / 强心针等一次性药物，副作用）→ 压力（⏳ 反扑期全身随机爆发，提前预警）
  → 器官三态恶化（⏳ 肺减速 / 肾毒伤 / 心视野受限）→ 封锁的代价（⏳ 短期封锁压制病情，
     但拖久了加速永久损伤 → 坏死 → 该区单元失联）→ 胜负
```

## 5. 架构

### 5.1 目录与职责

```
scripts/
├─ main.gd                  装配 + 输入 + 主循环（不做玩法决策）
├─ core/balance.gd          ★ 唯一数值入口
├─ world/
│   ├─ lung_gen.gd          肺地图生成（含装饰几何）
│   ├─ organ_map.gd         地图数据 + 碰撞判定（唯一真相源）
│   ├─ organ_view.gd        地图渲染（可换美术，不影响玩法）
│   └─ virus_population.gd  病毒模拟 + 粒子渲染（池/繁殖/尸体/带/引信/查询）
├─ units/
│   ├─ player_unit.gd       免疫单元实体
│   └─ tools/               手段：jet_system / purge_aura / aim_preview
├─ ui/                      hud（组装）/ hud_panel（图标面板 + 技能栏）/ minimap / ui_icons（图标加载）
└─ debug/                   map_selftest / map_probe / aim_probe / auto_sequence

assets/
├─ ui/icons/                ★ UI 图标素材包（svg + manifest.json），见 assets/ui/README.md
│   └─ README.md            规格 / 配色 / 三种替换方式（美术改图不动代码）
└─ （后续美术资源：角色、病毒、器官贴图按同类分目录）
```

### 5.2 依赖方向（**只允许单向**）

```
main ─→ world/*（生成、数据、渲染）
  └──→ units/*（依赖 world 的判定）
        └──→ ui/*（只读，显示）
debug/* ─→ 读 host 的公开状态（不反向修改玩法）
core/balance.gd ← 被所有层读，自己不依赖任何人
```

**禁止**：`world` 反向 import `units` 或 `ui`；`ui` 直接读 `pop._px` 这类内部数组；任何层写死平衡数值。

### 5.3 依赖注入而非全局单例

`project.godot` 里**没有 autoload**。所有跨模块引用都走显式 `bind(...)`：

```gdscript
pop.bind_organ(_map)          # 病毒需要地形
player_unit.bind(_map, pop)   # 单元需要地形 + 遮挡
jet.bind(pop)                 # 手段需要病毒池
aura.bind(pop)
```

好处：任何一层都能单独跑（自测 / 压测 / 单场景），不会出现隐式全局状态被跨测试污染。

## 6. 模块契约（改代码前先看这张表）

### 6.1 `OrganMap`（地图唯一真相源）

| API | 说明 |
|---|---|
| `size / organ_bounds / free_ratio / loops / clip_loops / build_ms` | 只读数据 |
| `solid_point(p)` / `solid_xy(x,y)` / `solid_cell(i,j)` | 点是否在肉壁（后两个是栅格快查） |
| `line_free(x0,y0,x1,y1)` | 线段是否全程无墙（步长 24，病毒探路用） |
| `blocked(a,b)` / `blocked_body(a,b,half)` | 轮廓段精确判定 / 带半径的体判定（玩家移动用后者） |
| `clearance(p)` / `is_lumen(p)` | 到最近墙的距离 / 是否流明 |
| `clip_span(center, axis, half, step)` | 把一条线段裁进可通行区：{a, b, len, trim, ok}。阻隔带两端不许插进肉壁就靠它 |
| `nearest_free(p, max_r)`（失败返回 `(-1,-1)`）/ `random_free_point(rng, r)` | 取点 |
| `walk_report(r)` | 可达率/连通块报告（自测与开局校验用） |
| `add_clip_circle / add_clip_capsule / build_clip_contours` | 生成期用 |
| `detail / decor` | 纯视觉几何，**不参与碰撞** |

### 6.2 `VirusPopulation`

| API | 说明 |
|---|---|
| `bind_organ(map)` / `arena_size()` / `reset()` | 生命周期 |
| `spawn_virus(kind, center, a, b, count, axis)` / `seed_blob(...)` | 播种 |
| `tick(dt)` | 固定步长推进（**只由 main 按 1/60 调用**） |
| `clear_fan(origin, dir)` | 射流扇形清除（返回命中数） |
| `purge_circle(pos, r, per_sec, dt)` / `harvest_circle(...)` | 净化场 / 拾取 |
| `resolve_block(origin, dir, dist)` | 算阻隔带会落在哪：{ok, a, b, len, dist, capped, trim, why}；预览与落位共用 |
| `place_block(origin, dir, dist)` / `add_fuse(pos)` / `path_blocked(a,b)` | 阻隔带落位 / 引信落位 / 移动遮挡 |
| `block_span(i)` | 只给验收用：第 i 条带子的端点与长度 |
| `live_count / corpse_count / live_by_kind / block_count / fuse_count / minimap_snapshot` | 只读查询 |
| `KIND_BLOB / KIND_BAND / KIND_CHAIN` | 形态常量（外部请用 `Virus.KIND_*`，别再复制一份） |

| 模块 | 契约 |

```powershell
$exe = 'E:\Godot\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe'

# 1) 地图自测：34 项（轮廓闭合 / 墙段数 / 流明占比 / 玩家可达率 / 死腔面积 / 生成耗时 / 确定性）

# 2) 实拍四张：射流 / 铺带挡弹道 / 引信 / 战术小地图（~27s 自动退出）
& $exe --path E:\gamecreation 'res://scenes/main.tscn' -- --shot

# 3) 俯瞰：核对叶形与肺泡尺寸
& $exe --path E:\gamecreation 'res://scenes/main.tscn' -- --overview

# 4) 压测：只跑模拟 60 秒，看单帧峰值
& $exe --path E:\gamecreation 'res://scenes/main.tscn' -- --stress

# 5) 贴墙滑行 A/B
& $exe --path E:\gamecreation 'res://scenes/main.tscn' -- --walk

# 5.5) 瞄准预览四张（阻隔带可放 / 养分不足 / 引信 / 真放下后），并验证落位接口
& $exe --path E:\gamecreation 'res://scenes/main.tscn' -- --aim

# 5.6) 阻隔带落位探针：7680 次随机拖拽，验证「端点不插进肉壁 + 整条不穿墙」
& $exe --headless --path E:\gamecreation --script res://scripts/debug/aim_probe.gd

# 6) 语法检查（改完任何脚本先跑这个，比开编辑器快）
& $exe --headless --path E:\gamecreation --check-only --script res://scripts/xxx.gd
```

**判定口径**（不要凭"命令没报错"就认为通过）：

- 自测必须 `34/34 PASS`，且 `reach ≥ 90%`、`comps` 尽量为 1（>2 说明地图又碎了）
- `--shot` 必须有 `[JET] hit>0` 与 `band_clip>0`（否则是验收摆位坏了，不是玩法坏了）
- `--stress` 单帧均值 < 6ms、峰值 < 12ms
- `--walk` 的 `slide path` 必须显著大于 `old path`（否则贴墙滑行退化了）
- `--aim` 的 `[AIM] block=true` 且 `len < 200`（被肉壁裁过）才算通过；`--aim_probe` 必须 `AIM PROBE: PASS`
- 改地图参数后，`shapes/free/reach/comps` 四个数必须一起看，别只看一个

## 10. 多 Agent 协作规范

### 10.1 角色分工（按能力画像，不按工具名）

| 角色 | 负责范围 | 建议能力画像 |
|---|---|---|
| **架构 / 代码 Agent** | `scripts/core`、`scripts/world`、`scripts/main.gd` | 长上下文 + 强类型/重构能力；能读全量代码再动手 |
| **机制 / 数值 Agent** | `balance.gd`、病毒三形态、手段数值、关卡机制设计 | 逻辑推演与数值敏感；能写机制文档、能跑压测对拍 |
| **视觉 / 表现 Agent** | `organ_view` 装饰层、粒子观感、UI、截图核对 | 多模态看图能力；能用截图判断"像不像肉" |
| **文档 / 交接 Agent** | `docs/*`、任务看板、验收记录 | 归纳与一致性；负责把口头结论落成可执行条目 |

**并行原则**：一个 Agent 同一时间只改一个目录。`world` 与 `units` 可以并行，`core/balance.gd` 是串行瓶颈（改它的人排队）。

### 10.2 目录所有权（避免互相踩）

| 目录 | 谁可以改 |
|---|---|
| `core/balance.gd` | 机制 Agent（其他 Agent 只能提 PR 建议） |

### 10.6 已知坑（血泪，别重走）

- `clip_sdf` 内=0、外>0；要「内缩距离」用 `clip_inside_dist(p)`。
- 改肺泡尺寸**必须**同步复核 `MAX_DOOR_GAP`，否则会静默生成进不去的小岛（`comps` 会飙到 5~8）。
- `--check-only` 抓不到「类型推断失败」（`var d := 某个 Variant - Vector2`），跑一次真场景才发现；`var d: Vector2 = ...` 显式标注。
- PowerShell 工具偶发吞 stdout：把输出重定向到文件再 `Get-Content`。
- GitHub 推送常 `Connection was reset`：直连重试 3~5 次、间隔 15~25 秒。
- 前台命令超 15s 自动转后台，需要 `TaskOutput` 取结果；Godot 进程残留要 `Get-Process *Godot* | Stop-Process -Force`。
- 地形有两套口径：`_solid` 栅格（8px 采样，病毒/玩家走它）与 `blocked()` 轮廓段（精确，画出来的是它）。
  两者在相切褶皱处会差不到一格 —— 凡是「必须精确」的判定（阻隔带落位）要用 `blocked()` 复核，别只用栅格。
