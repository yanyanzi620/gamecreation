# 净化协议 · 音频系统

> 素材在 `assets/audio/`（独立素材包，规格与替换方式见那边的 `README.md`）。
> 本文只说**代码怎么把事件变成声音**，以及后续要扩什么。

---

## 1. 一句话结构

```
玩法层（main / virus_population）  --事件名-->  AudioDirector  --读 manifest-->  wav
        「jet_fire」                              「放哪段、多响、能不能重复」
```

- 玩法层**不认识文件名**：`audio.play("jet_fire")`，仅此而已。
- 事件 → 文件 / 音量 / 音高抖动 / 最短间隔，全在 `assets/audio/manifest.json`。
- 所以「换音效」= 换文件或改 json，**不改代码**；「加音效」= 加一行 json + 一行 `play`。

## 2. 模块

| 文件 | 职责 |
|---|---|
| `scripts/audio/audio_director.gd` | 读 manifest、加载 stream、播放器池（12 发）、同名事件节流、音高抖动、SFX/BGM 双总线、无头静音、`M` 键总开关 |
| `scripts/world/virus_population.gd` | `push_event(kind, pos)` 记事件、`drain_events()` 交给 main；上限 64 条，防掉帧堆积 |
| `scripts/main.gd` | `_drain_audio()` 每帧把事件转成 `play()`；射流在 `fire_at()` 里直接发声；拾取按 `aura.picked` 增量发声 |

**为什么不让 `virus_population` 直接播**：那是模拟层，一帧可能发生几十次击杀；集中到 main 才好做节流和优先级。事件队列也让「以后要做 3D 定位音 / 打击感镜头」时只需要换消费方。

## 3. 事件表（当前接线）

| 事件 | 谁触发 | 触发点 |
|---|---|---|
| `jet_fire` | `main.fire_at()` | 射流真正打出去（冷却拦截的不算） |
| `jet_hit` | `main.fire_at()` | 同一次射击 `hit > 0` |
| `pickup` | `main._drain_audio()` | `aura.picked` 增加（每次拾取一批就响一次） |
| `block_place` | `virus_population.place_block()` | 带子放下（闪烁期） |
| `block_arm` | `virus_population._tick_blocks()` | 闪烁结束、真正生效 |
| `block_die` | 同上 | 60 秒到点自溶 |
| `fuse_place` | `virus_population.add_fuse()` | 引信落位 |
| `fuse_pulse` | 同上 | 引信开始清场 |
| `bgm` | `main._ready()` | 进关起播，整段循环 |

## 4. 总线与混音

运行时自动建两条总线，不依赖项目里预设的默认总线：

```
Master
├─ SFX   音效（12 个 AudioStreamPlayer 轮流用）
└─ BGM   背景（单个播放器，循环）
```

- 想整体调小音效 → 在 Godot 编辑器音频面板里拉 `SFX` 总线音量，或改代码里 `_ensure_buses()`。
- `M` 键 = 全局静音（停 BGM、停所有音效，再按恢复）。
- 无头模式（`--headless`，自测/CI）自动静音，不会刷音频设备告警。

## 5. 防「糊成一片」的三道闸

| 闸 | 参数 | 作用 |
|---|---|---|
| 事件节流 | `min_gap_ms` | 同名事件最短间隔：射流 40ms，拾取 35ms，带/引信 120ms |
| 音高抖动 | `pitch_jitter` | ±10%~18%，同一个 wav 反复响也不会像卡带 |
| 播放器池 | `VOICES = 12` | 最多 12 发同时响，超了挤掉最老的（不叠成噪声墙） |

## 6. 调试与验收

```powershell
# 把每次播放打到控制台（事件名 / 音量 / 音高）
& $exe --path E:\gamecreation 'res://scenes/main.tscn' -- --audio --shot

# 只看加载情况（不发声）
& $exe --headless --path E:\gamecreation 'res://scenes/main.tscn' -- --shot
#   期望：[AUDIO] events=9 streams=9 muted=true
```

## 7. 下一步（还没做）

| 需求 | 缝在哪 |
|---|---|
| 音量设置界面（Master/SFX/BGM 三条滑杆） | `_ensure_buses()` 已建好总线，直接读写 `AudioServer.set_bus_volume_db` |
| 3D 定位音（远处病毒孵化的窸窣声） | 事件本来带 `p`（世界坐标），换 `AudioStreamPlayer2D` 即可，队列不用改 |
| 伤害/低血量的心跳、器官坏死的低频压迫 | 加事件名 + json 一行；靠 `min_gap_ms` 控频率 |
| 打击感（命中顿帧、震屏） | 同一个事件队列，加一个「演出层」消费方，别塞回模拟层 |
