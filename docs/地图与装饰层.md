# 地图与装饰层（L1 肺）

> 只讲"地形长什么样、怎么画上去"。玩法数值在 `scripts/core/balance.gd`，病毒规则在 `docs/病毒模型与攻击机制.md`。

## 1. 一句话

地图 = **程序化生成的肺泡泡沫**（`lung_gen.gd`）→ **掩码/轮廓**（`organ_map.gd`）→ **两张烘焙贴图 + 三批批量线**（`organ_view.gd`）。
墙的判定 100% 来自 `OrganMap`，画法随时可以整体换成美术资源，不会影响任何玩法逻辑。

## 2. 生成链路

| 步骤 | 文件 | 关键点 |
|---|---|---|
| 器官轮廓 | `lung_gen._silhouette` | 8 排宽度单调递减的胶囊拼出"上宽下窄"叶形；左右镜像；胸膜轮廓只做裁切，不做碰撞 |
| 肺泡铺点 | `lung_gen._lobe` | 六边形节距 = `ALV_R_MAX*2 + MIN_SEPTUM`；贴胸膜的肺泡按可用距离缩径，所以肺的形状是"肺泡自己长出来的" |
| 位置松弛 | 同上 | 5 轮推挤，保证任意两颗之间留出 `MIN_SEPTUM` |
| 邻接 + 生成树 | 同上 | 只认节距 1.16 倍内的邻居；随机生成树上再加 `EXTRA_LINK_CHANCE` 的旁门形成环路 |
| 开门 | `lung_gen._door` | 门宽按 `DUCT_R` 分三档（小门/中门/大门），全长受 `MAX_DOOR_GAP` 约束 |
| 支气管 | `lung_gen._airway` | 主干 → 隆突 → 6 个肺门分支；分支端点必须连最近肺泡圆心，否则两叶会断成三块 |
| 掩码与轮廓 | `OrganMap.build` | `PIX 8` 采样栅格 + 轮廓段碰撞；`solid_xy/line_free` 是给病毒探路用的快速版 |

### `MAX_DOOR_GAP` 这个数为什么是 168

肺泡半径从 70~80 放大到 118~134 之后，相邻腔室之间的空隙也跟着变大。旧代码写死 `> 110 就跳过开门`，
结果大量生成树边被砍掉，地图碎成 5~8 块孤岛（`reach` 只有 96%）。
按新节距（`2*134 + 62 = 330`，邻接上限 `330*1.16 ≈ 383`）反推，最坏空隙 = `383 - 118 - 118 ≈ 147`，
取 168 留出余量。**改肺泡尺寸时必须同步复核这个常量**，否则会静默生成进不去的小岛。

## 3. 装饰层（可开关）

美术资源到位之前，用纯程序化几何把"死平的色块"压掉。全部**不参与碰撞**。

### 3.1 两层构成

| 层 | 内容 | 实现 | 开销 |
|---|---|---|---|
| 烘焙贴图 | 腔室球状纵深（近壁暗、腔心亮）+ 组织噪声 | `organ_view._distance_field()` + `_bake()` | 载入时一次性，~600ms（含两张图） |
| 批量线 | 沿壁弧、间隔小突、毛细血管弧、隔膜弦线、上皮斑点 | `organ_view.draw_multiline`，按 3 层配色分批 | **3 个 draw call**，与肺泡数量无关 |

纵深靠**倒角距离场**：从"墙/体外"出发做两遍（正扫 + 反扫）`+3/+4` 倒角，得到每个流明格子到最近的墙的长度，
再 `smoothstep` 映射到 `COL_LUMEN → COL_LUMEN_LIT`。这比逐格调 `clearance()` 便宜三个数量级。

### 3.2 装饰几何从哪来

`lung_gen._alv_detail(m, rng, c, r)` 在铺肺泡时顺手生成，存进 `OrganMap.detail`：

```
detail[i] = [PackedVector2Array 折线, 层号]
  层 0  沿壁弧（r*0.94）+ 间隔小突（起点故意落在 r+8，压到墙线上，看起来是"从墙上长出来"）
  层 1  毛细血管弧（r*0.55~0.82，带径向抖动，别像同心圆）
  层 2  隔膜弦线（跨腔的一道浅弧，把大片空腔切成有结构的几块）+ 上皮斑点
```

`organ_view._build_detail()` 把这些折线摊平成 `draw_multiline` 需要的"成对点"数组，按层各存一份。
**关键约束**：一条折线要拆成 `N-1` 个点对，否则 `draw_multiline` 会把不相关的两段连起来。

### 3.3 开关

| 方式 | 用法 |
|---|---|
| 运行时 | 按 `F`，`[DECOR] on=true/false` 打日志 |
| 默认值 | `Balance.DECOR_ON` |
| 命令行 | `-- --decor-off`，出纯灰盒对比图 |

关掉时不只是少画线：`_baked` 会切到 `_baked_off`（平涂版），所以是**完整的"美术层/灰盒层"切换**。
两张图在 `set_map` 时都烘好，切换零卡顿。小地图固定用平涂版（缩略图上装饰只会糊成一团）。

## 4. 后期接美术时怎么改

1. **整体换底图**：给 `organ_view.tissue_texture` 塞一张 6200×2300 的手绘/生成图，`_bake` 自动不再被使用（贴图优先）。
2. **保留纵深、只换细线**：把 `_alv_detail` 换成从外部数据（JSON/SVG 描线）读折线，`draw_multiline` 那一段完全不用动。
3. **换成 TileMap / Sprite2D**：因为碰撞完全来自 `OrganMap`，把 `OrganView` 整个节点换掉即可，病毒与玩家不受影响。
4. **做发光/后处理**：`OrganView` 在 `z_index = -2`，病毒 `-1`，玩家 `0`；给相机挂 `CanvasLayer` + shader 即可，不必拆图。
