# 地图与装饰层（L1 肺）

> 只讲"地形长什么样、怎么画上去"。玩法数值在 `scripts/core/balance.gd`，病毒规则在 `docs/病毒模型与攻击机制.md`。

## 1. 一句话

地图 = **程序化生成的肺泡泡沫**（`lung_gen.gd`）→ **掩码/轮廓**（`organ_map.gd`）→ **两张烘焙贴图 + 五批批量线**（`organ_view.gd`）。
墙的判定 100% 来自 `OrganMap`，画法随时可以整体换成美术资源，不会影响任何玩法逻辑。

## 2. 生成链路

| 步骤 | 文件 | 关键点 |
|---|---|---|
| 器官轮廓 | `lung_gen._silhouette` | 一圈控制点经闭合 Catmull-Rom 采样成连续多边形；内侧肺门有凹口；左右镜像；只做裁切，不做碰撞 |
| 肺泡铺点 | `lung_gen._lobe` | 六边形节距 + 随机抖动；贴胸膜的肺泡按可用距离缩径，肺的形状是"肺泡自己长出来的" |
| 主战厅 | 同上 | 每叶两个放大的肺泡（`HUB_R`），一个靠肺门、一个在深部；连到主战厅的门至少 50 半径，形成可走位的大空间 |
| 位置松弛 | 同上 | 7 轮推挤，保证任意两颗之间留出 `MIN_SEPTUM` |
| 邻接 + 生成树 | 同上 | 只认节距 1.18 倍内的邻居；随机生成树上再加 `EXTRA_LINK_CHANCE=0.38` 的旁门形成环路 |
| 开门 | `lung_gen._door` | 门宽按 `DUCT_R` 分三档；主战厅的门有最小宽度；全长受 `MAX_DOOR_GAP` 约束 |
| 支气管 | `lung_gen._airway` | 主干 → 隆突 → 每侧肺门 → 两条按距离挑选的分支 + 一条深部支路；端点必须连最近肺泡 |
| 掩码与轮廓 | `OrganMap.build` | `PIX 8` 采样栅格 + 轮廓段碰撞；流明相交处做 `SMOOTH_UNION` 圆角；轮廓步长 16、RDP 容差 1.25 |

### `MAX_DOOR_GAP` 这个数为什么是 184

新节距 `2*136 + 62 = 334`，邻接上限 `334*1.18 ≈ 394`，最坏间隙 `394 - 110 - 110 ≈ 174`。
取 **184** 留 10 单位余量。**改肺泡尺寸或邻接倍率时必须同步复核这个常量**，否则生成树边会被静默砍掉、
留下进不去的小岛（`comps` 会飙到 5~8）。四个验收种子当前均为 1~2 块、可达率 ≥99.8%。

## 3. 装饰层（可开关）

美术资源到位之前，用纯程序化几何把"死平的色块"压掉。全部**不参与碰撞**。

### 3.1 两层构成

| 层 | 内容 | 实现 | 开销 |
|---|---|---|---|
| 烘焙贴图 | 内壁接触阴影、组织厚度、定向高光、低频组织色差 | `organ_view._signed_distance_field()` + `_bake()` | 换图时一次性，两张图约 1s |
| 批量线 | 沿壁弧、间隔小突、毛细血管弧、隔膜弦线、上皮斑点 | 3 批 `draw_multiline` | 3 次绘制，与肺泡数量无关 |
| 肉壁纹理 | 组织内小肺泡圆环 | 静态点对预合并成 2 批 `draw_multiline` | 2 次绘制（原来每帧上千次 `draw_arc`） |
| 轮廓 | 肉壁深色基底 + 窄高光、胸膜双层线 | 换图时缓存成 `_wall_rings / _clip_rings` | 只遍历缓存，不重复 `duplicate` |

立体感来自**有符号距离场**：流明为正、组织为负，绝对值都是到壁面的世界距离。
流明侧直接复用 `OrganMap.distance_field()`，只额外做组织侧两遍倒角；距离场梯度就是 2D 法线，
固定右上光源据此产生"组织边缘受光、腔体近壁背光"的厚度，不需要 3D 网格或逐帧计算。
`_baked_off` 只做平涂，不计算光照，所以灰盒对比版仍然便宜。

### 3.2 装饰几何从哪来

`lung_gen._alv_detail(m, rng, c, r)` 在铺肺泡时顺手生成，存进 `OrganMap.detail`：

```
detail[i] = [PackedVector2Array 折线, 层号]
  层 0  沿壁弧（r*0.94）+ 间隔小突（起点故意落在 r+8，压到墙线上，看起来是"从墙上长出来"）
  层 1  毛细血管弧（r*0.55~0.82，带径向抖动，别像同心圆）
  层 2  隔膜弦线（跨腔的一道浅弧，把大片空腔切成有结构的几块）+ 上皮斑点
```

`organ_view._build_detail()` 把这些折线摊平成 `draw_multiline` 需要的"成对点"数组，按层各存一份。
**关键约束**：一条折线要拆成 `N-1` 个点对，否则 `draw_multiline` 会把不相关的两段连起来。

### 3.3 开关

| 方式 | 用法 |
|---|---|
| 运行时 | 按 `F`，`[DECOR] on=true/false` 打日志 |
| 默认值 | `Balance.DECOR_ON` |
| 命令行 | `-- --decor-off`，出纯灰盒对比图 |

关掉时不只是少画线：`_baked` 会切到 `_baked_off`（平涂版），所以是**完整的"美术层/灰盒层"切换**。
两张图在 `set_map` 时都烘好，切换零卡顿。小地图固定用平涂版（缩略图上装饰只会糊成一团）。

## 4. 后期接美术时怎么改

1. **整体换底图**：给 `organ_view.tissue_texture` 塞一张 6200×2300 的手绘/生成图，`_bake` 自动不再被使用（贴图优先）。
2. **保留纵深、只换细线**：把 `_alv_detail` 换成从外部数据（JSON/SVG 描线）读折线，`draw_multiline` 那一段完全不用动。
3. **换成 TileMap / Sprite2D**：因为碰撞完全来自 `OrganMap`，把 `OrganView` 整个节点换掉即可，病毒与玩家不受影响。
4. **做发光/后处理**：`OrganView` 在 `z_index = -2`，病毒 `-1`，玩家 `0`；给相机挂 `CanvasLayer` + shader 即可，不必拆图。
