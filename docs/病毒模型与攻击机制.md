# 病毒模型与攻击机制（实现版 v0.3）

> 对应代码：`scripts/world/virus_population.gd`、`scripts/units/tools/jet_system.gd`、`scripts/units/tools/purge_aura.gd`
> 演示场景：`scenes/demo/virus_showcase.tscn`

## 1. 表示

病毒**不是场，也不是节点云**，而是一堆粒子。

| 层 | 内容 |
|---|---|
| 粒子 | `位置 / 半径 / 年龄 / 冷却 / 形态 / 主轴角 / 病毒ID` |
| 病毒 | 一组粒子 + 一个主轴角 + 一个形态枚举 |
| 边界 | 不存曲线，边界就是**密度前沿** |

容量：`MAX_LIVE 4200` / `MAX_CORPSE 1200`，渲染走单个 MultiMesh（1 次 draw call）。

## 2. 三种形态

三者共用同一套复制规则，**差别只在三个参数**：方向权重表、每格容量、步长。

| 形态 | 枚举 | 格容 | 方向权重（正前 / ±45° / 侧 / 反） | 步长 | 长成什么 |
|---|---|---|---|---|---|
| 圆周 BLOB | `KIND_BLOB` | 7 | 1 / 1 / 1 / 1 | 16~30 | 不规则圆盘 |
| 带状 BAND | `KIND_BAND` | 4 | 6.5 / 1.2 / 0.5 / 0.3 | 16~30 | 连续长条，长直段 + 偶尔折线 |
| 跳跃链 CHAIN | `KIND_CHAIN` | 3 | 10.0 / 0.1 / 0.04 / 0.04 | **32~52** | 稀疏点链，段与段之间有断口 |

**链和带怎么区分**（这是两者唯一的实质差别，也是观感差别）：

| | 带状 BAND | 跳跃链 CHAIN |
|---|---|---|
| 密度 | 连续、成片 | 一眼看得出是一颗一颗的点 |
| 步长 | 16~30（粒子挨着） | 32~52（粒子之间有空气） |
| 宽窄 | 有带宽（±45° 权重 1.2） | 近乎单线（±45° 只有 0.1） |
| 前方堵死时 | 往两侧挤，继续加宽 | **跳 112 单位**落在对面，形成断口 |

**打分公式**：`score = 方向权重 × (格容 - 该方向邻格已有粒子数)`，取最大者生长。

这个公式同时满足两件事：
- 形状由权重主导（带只往前长、链只往前长）；
- 再满的格子也挡不住一个**完全空的缺口** —— 这就是「填洞」。

## 3. 生长三条铁律

1. **复制式扩张**：冷却结束 → 生一个新粒子，本体不变大。
2. **朝最空的邻格生**：八方向各探 30 单位，前沿外推 + 缺口回填。
3. **无终身配额**：只受冷却（1.0~2.0 秒）+ 格子容量约束。

> 第 3 条是踩坑换来的：有过「配额制」的版本，缺口边缘的老粒子配额用完就不再繁殖，
> 结果咬痕永远填不上。配额是错的，空间才是唯一约束。

链形态额外有**跳跃**：正前方 ±23° 内全满 → 沿主轴跳 112 单位（约 3.7 格）落一颗新粒子，
形成断口；跳跃失败才退回去做侧向/回填。

## 4. 攻击与控场

| 手段 | 代码 | 定位 | 参数 |
|---|---|---|---|
| 射流 | `jet_system.gd` | 主动、定向、高频 | 320 长 / ±16° / **0.50 秒** |
| 净化场 | `purge_aura.gd` | 被动、贴身、持续 | 半径 108 / 55 个每秒 |
| 养分拾取 | `purge_aura.gd` | 自动、无操作 | 半径 340 / 45 个每秒 |
| 阻隔带 | `virus_population.gd#place_block` | 主动、封路、**消耗 30 养分** | 260 长 / 0.45 秒生效 / 30 秒自溶 |

- 射流：左键**点一次 = 一发**（按下边沿触发，按住不连发），锥内 live 全转尸体。
- 净化场：站在病毒里也不会被瞬间淹没，是「近身安全区」。
- 养分拾取：只吃**躺了 1 秒以上**的尸体，所以射流划过的地方能先看到疤，再变成光点飞回来。

## 5. 阻隔带

规则（精度按设计表）：

- 只能落在**单元朝前的正前方**（`BLK_OFFSET 140`），不能正交吸附、不能拖拽。
- 固定长度 260，释放后**闪烁 0.45 秒才生效**（黄色闪烁 = 还没封住，青色 = 已封住）。
- 生效前病毒已经穿过去 → 那颗病毒只是**减速**（繁殖冷却 ×2.4）。
- 生效后病毒无法穿过；带子**有限长**，所以病毒从两端绕过去 —— 这就是圆盘病毒撞墙时的「绕射」。
- 只拦病毒，不拦玩家；30 秒后自溶，缺口重新打开。
- **与「器官隔离」是两件事**：阻隔带永远不断血，所以不会加速坏死。

实现方式：生长落点前做一次线段相交判定。被拦住的方向在 `_pick_dir` 里直接跳过，
于是「最空的邻格」会自动变成沿带子方向或带子两端 —— 绕射是**涌现**出来的，不需要单独写算法。

## 5.5 养分经济

养分是唯一资源，来路只有一条：**病毒尸体**。

```
病毒死亡 -> 尸体(灰) --躺 1 秒--> 进入拾取范围 -> 金色光点飞向单元 -> 养分 +1
```

- 拾取半径 340（比射程 320 略大），所以**视线内清掉的都能收**，不需要走过去捡。
- 拾取是自动的，玩家不需要任何操作；光点以 460 px/s 飞向单元，到位才入账。
- 尸体躺不满 1 秒不吃 —— 保证「刚打完那一瞬间」还能看到疤。
- 支出：**阻隔带 30 养分 / 条**。放不出来就是放不出来，不会自动降级。

这条链路把「攻击」和「控场」绑到了一起：打得越多 → 养分越多 → 越封得住；
但封得越多 → 越打不到近处的病毒 → 养分收入下降。这是**故意留的负反馈**。

## 6. 消除与视觉三层信息

| 颜色 | 含义 | 生命周期 |
|---|---|---|
| 绿 / 琥珀 / 品红 | 活病毒 | 持续复制 |
| 灰 | 尸体（战斗疤痕） | 30 秒衰减 |
| 空腔 | 被打空的区域 | 数秒内被绿色回填 |

尸体**不占格子、不扩散、不复生**，所以回填时可以透过尸体生长 —— 视觉上就是
「绿色从灰疤里重新长出来」。

## 7. 已知待调项

- 射流 0.5 秒一发是否过强（单发清除量约 4~5% / 团）。
- 带状宽度（当前约 200 单位）是否还需要更窄。
- 链的点间距（32~52）是否太稀。
- 阻隔带 260 长 / 30 秒寿命 是否合适；是否需要限制同时存在的数量。
- 墙体 / 器官边界交互尚未实现（粒子会直接贴到 arena 边界）。
